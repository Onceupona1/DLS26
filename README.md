# DLS26 Tournament

Simple web app for running a Dream League Soccer 2026 (DLS26) tournament.

## Features
- Player sign up
- Automatic fixture generation
- Match scheduling (8:30 PM – 9:30 PM)
- Leaderboard tracking
- Prize distribution (top 5 + admin cut)

## How it works
1. Players register
2. System adds them to the tournament
3. Fixtures are generated automatically
4. Players play their assigned matches
5. Results are recorded
6. Rankings update
7. Winners are paid

## Prize Distribution
- Admin takes 10%
- Remaining prize pool:

1st - 40%  
2nd - 25%  
3rd - 15%  
4th - 10%  
5th - 10%  

## Notes
- Matches must be played within the time window
- No duplicate players
- Results should be verified
